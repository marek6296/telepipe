# Fanvue owner media messages
Owner attaches up to20 images/videos in a Fanvue Social chat, chooses exact Vault items or multiple local files, optional caption, Free or PPV (USD cents, min300). The displayed total unlock price applies to the whole bundle. Explicit Send queues the immutable recipient/media/price/caption intent; never sends simply by picking/uploading. Web and Telegram Mini use the same component. Existing worker seen/composition/freshness/unknown-outcome semantics stay.

Browser sends file bytes straight to Fanvue's signed multipart URLs with progress, never through Next/server actions. Upload session/part signing/completion/readiness and live paged Vault reads run on the existing leased tenant worker via private owner request queue; OAuth credentials stay worker-only. UI cannot send until all media are ready. Closing during upload warns via UI text: bytes require app open; accepted send queue persists after close. No automatic price inference. Read-side operations never mark chat seen. Current confirmed owner/model/account scope is checked at every boundary. Selected media IDs are revalidated against creator at send-time. Unknown sends are never retried. No customer test messages.
