### Task W1: Migrácia 007 — auth link, RLS, tg_login_jobs *(blokuje všetko ostatné)*

**Files:** Create `supabase/migrations/007_web_access.sql`

- [ ] 1. SQL — tri časti:
  **(a) accounts ↔ auth.users:** `alter table accounts alter column id drop default;` + FK `references auth.users(id) on delete cascade` + trigger `on_auth_user_created` (after insert on auth.users → insert into accounts (id, email) values (new.id, new.email) on conflict do nothing) — security definer, pinned search_path (vzor 005).
  **(b) RLS policies (role authenticated):**
  - accounts: select using `id = auth.uid()`
  - models: select/insert/update/delete using/check `account_id = auth.uid()`; ALE stĺpce `claimed_by, heartbeat_at, tg_session_enc, credit_*` klient nemení — insert/update cez RLS + column grants: `revoke update on models from authenticated; grant update (name, status, status_reason, tg_api_id, owner_chat_id, updated_at) on models to authenticated;` + RPC `set_model_status(p_model uuid, p_status text)` (security definer, kontrola vlastníctva + whitelist prechodov draft→active, active→paused, paused→active; error→active zakázané ak status_reason='session_revoked')
  - persona/behavior/settings/photos/voices: all ops using `model_id in (select id from models where account_id = auth.uid())` — na behavior column grant bez `eleven_key` (fáza 3)
  - dm_users, dm_messages, facts, episodes, open_loops, self_claims, judge_log, voice_clips, voice_jobs, photo_sends, voice_sends: **select only** (rovnaké using)
  - usage_events: select using `account_id = auth.uid()`
  - pricing: nič
  - grants: `grant select/insert/update/delete` podľa vyššie uvedeného na `authenticated` (Postgres default nedáva tabuľkám nič — policies bez grants nestačia!)
  **(c) tg_login_jobs:** id bigint identity pk, model_id uuid ref models cascade, account_id uuid ref accounts cascade, phase text check in ('send_code','code_sent','verify_code','need_password','verify_password','done','error') default 'send_code', phone text, api_id int, api_hash_enc text default '', code_enc text default '', password_enc text default '', phone_code_hash text default '', tmp_session_enc text default '', error text default '', created_at/updated_at timestamptz, expires_at timestamptz default now()+interval '10 minutes'. RLS: klient insert (check account_id=auth.uid() and model vlastný) + select vlastných + update len stĺpcov code_enc/password_enc/phase (grant update (code_enc, password_enc, phase, updated_at)); worker service_role vidí všetko. Index na (phase) where phase in ('send_code','verify_code','verify_password'). Grant insert/select/update authenticated.
- [ ] 2. Apply cez MCP `apply_migration` + over `get_advisors(security)` — žiadne ERROR.
- [ ] 3. RLS test cez execute_sql: vytvoriť 2 auth userov (`auth.users` insert s bcrypt heslom je zložitý — použiť `set local role authenticated; set local request.jwt.claims '{"sub":"<uuid>"}'` simuláciu), overiť: user A select models → len svoje; update credit_balance_usd → denied; select pricing → denied/0 riadkov.
